# Stinger — FBNF Team 21592

Interactive 3D animation and schematic of **Stinger**, Fast But Not Furious (FTC Team 21592)'s 2026–27 BIOBUZZ robot:
intake, straight transfer, turret, and an underhand shooter on two goBILDA Hogback 72 mm wheels.

Live page: https://kimnggnmik.github.io/stinger/

The model is a mock-up rebuilt from match video, not CAD. Every estimate (ball size, wheel size, turret height, grip,
motor speed, belt ratio, ball mass, spin, air density, aim point, pollen to tip the hive) can be changed in the
**Math** tab; the page address keeps your numbers so you can share them.

Source and build scripts live with the team's files (`Robot/Stinger page source`); this repo holds the built page.
